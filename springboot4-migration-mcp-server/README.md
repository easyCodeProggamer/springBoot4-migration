## Step4: configure copilot in your VS code
https://code.visualstudio.com/docs/copilot/overview

## Step5: setup mcp server in VS code
 
   ```
   1. ctrl + shift + p

   2. MCP: add server
   
   3. HTTP
   
   4. enter your mcp server url ( http://localhost:8081/mcp )
   
   5. workSpace
```
